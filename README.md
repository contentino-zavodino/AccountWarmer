# 🚀 Social Account Warmer (BitBrowser + Playwright)

> **Профессиональный инструмент автоматического прогрева аккаунтов TikTok и YouTube Shorts через антидетект-браузер BitBrowser с глубокой имитацией человеческого поведения.**

Проект разработан для арбитражных команд, медиабайеров и контент-мейкеров. Основная цель софта — естественное наращивание траста свежих и отлежавшихся аккаунтов, безопасное формирование рекомендательных алгоритмов и исключение любых рисков детекта автоматизации антифрод-системами ByteDance (TikTok) и Google (YouTube).

---

## 📌 Архитектура и выбор браузера: почему BitBrowser?

В качестве основного движка автоматизации используется **BitBrowser**:
1. **100% бесплатный и неограниченный Local API & CDP:** в отличие от других решений (например, Dolphin{anty}, где API заблокирован на бесплатном тарифе), BitBrowser предоставляет полноценный доступ к Local API (`http://127.0.0.1:54345`) и порту отладки Chrome DevTools Protocol без платных подписок.
2. **Аппаратная маскировка отпечатков (Fingerprints):** нативные подмены Canvas, WebGL, AudioContext, WebRTC, Client Rects и шрифтов.
3. **Умная авто-маршрутизация профилей:** скрипт автоматически анализирует ваши профили в BitBrowser:
   * При запуске режима **YouTube Shorts** софт сам находит и открывает профили под YouTube (например, `YouTube1`);
   * При запуске режима **TikTok** — профили под TikTok (например, `TikTok1`);
   * При комбинированном режиме — запускает параллельный прогрев.
4. **Устойчивость к сбоям сокетов (Auto-Retry):** встроен защитный механизм при ошибках `socket hang up`. Если браузер ещё закрывает предыдущую сессию, софт делает паузу, сбрасывает зависший процесс и безопасно перезапускает профиль.

## 🛡️ Комплекс мер безопасности и антидетект-инженерии

В софт заложен многоуровневый аудит уязвимостей, предотвращающий баны, теневые блокировки (Shadowban) и проверки по номеру:

### 1. Естественная кинематика мыши (Кривые Безье с микро-дрожанием)
* **Никаких прямолинейных перемещений и мгновенных телепортаций:** курсор перемещается по кубическим сплайнам Безье с параметрическим ускорением и замедлением (easing).
* **Человеческий тремор:** на траекторию накладывается естественный случайный шум по Гауссу, имитирующий микродрожание руки реального пользователя.
* **Физика клика:** реалистичные микрозадержки между нажатием (`mousedown`) и отпусканием (`mouseup`) кнопки (60–120 мс).

### 2. Плавный инерционный скролл (Smooth Inertial Scroll)
* Стандартные инструменты автоматизации посылают дискретные резкие рывки колеса мыши (`wheel` на 200px за 0 миллисекунд), что мгновенно фиксируется JS-слушателями антифрода.
* Наш модуль `smooth_human_scroll` разбивает каждое движение на **12–16 микро-касаний по синусоидальной кривой** с задержками по 10–20 мс. Визуально и программно это неотличимо от скольжения пальца по тачпаду MacBook.

### 3. Решение проблемы «слабого слайда» и преодоление Scroll-Snap
* Веб-плееры TikTok и Shorts используют технологию *CSS Scroll-Snap* (примагничивание видео). При слабом импульсе ролик соскакивает обратно на текущее видео.
* Модуль `decisive_flick_scroll` выполняет энергичный бросок с ускорением на старте (950–1200px за 4–5 микро-шагов), чисто переключая плеер.
* **Сброс фокуса (`activeElement.blur()`):** перед любым свайпом бот снимает фокус с ранее нажатых кнопок (лайка/комментов), исключая потерю фокуса клавиатуры.
* **Автодоводка на Shorts:** скрипт контролирует смену URL ролика. Если видео застряло, бот нажимает на нативную кнопку стрелки вниз (`#navigation-button-down`) или делает дожим.

### 4. Полный отказ от клавиатурных читов
* Боты часто используют шорткаты `KeyL` (лайк) или `KeyC` (комментарии). Обычные пользователи ПК практически никогда не пользуются этими горячими клавишами.
* В софте шорткаты **полностью отключены**. Все действия выполняются **исключительно физическим наведением и кликом в центр кнопки**.
* **Никакого двойного клика на ПК:** на смартфонах дабл-тап ставит лайк, но на ПК двойной клик мышью просто ставит плеер на паузу. Бот находит реальные координаты кнопки сердечка внутри видимой области экрана и кликает строго по ней.

### 5. Трёхуровневая защита от рекламы и редиректов (Ad & Quarantine Guard)
Случайный клик по рекламному ролику (In-Feed Ads) может увести профиль на внешний интернет-магазин и сломать прогрев:
* **Уровень 1 (Ad Detection):** сканирование рекламных бейджей (`Sponsored`, `Реклама`, CTA-кнопок `Shop now`, `Learn more`). На рекламных роликах **полностью заблокированы лайки, подписки и открытие комментариев**. Бот задерживается на рекламе всего на 2 секунды (как человек, которому неинтересна реклама) и сразу свайпает дальше.
* **Уровень 2 (Popup Guardian):** фоновый сторож на уровне браузерного контекста. Если сторонний скрипт пытается открыть новую вкладку на внешний домен, бот **моментально (за 0.5 сек) закрывает эту вкладку**.
* **Уровень 3 (Navigation Guard):** если основная страница ушла на чужой URL, бот мгновенно возвращает браузер обратно в `/foryou` или `/shorts`.

### 6. Безопасное чтение комментариев (Zero-Spam Policy)
* Бот **не оставляет текстовых комментариев и эмодзи** (оставлять спам-комментарии на этапе прогрева — 100% триггер флуд-контроля и теневого бана).
* Бот имитирует чтение: находит кнопку комментариев, открывает панель, плавно прокручивает список с паузами 1.5–3.0 секунды на чтение, делает естественные микро-откаты взгляда назад (20%) и аккуратно закрывает панель кликом по крестику.

### 7. Поведенческие профили просмотра (Watch Profiles)
Время просмотра рассчитывается динамически для каждого ролика:
* **70% — Быстрый пропуск (Quick Swipe):** 2.0 – 5.0 сек.
* **22% — Заинтересованный просмотр (Medium Watch):** 6.0 – 11.0 сек.
* **8% — Полный досмотр (Long Watch):** 12.0 – 19.0 сек.

### 8. Сохранение нативного Viewport и Stealth
* Исключено принудительное изменение `page.set_viewport_size()`, которое ломает отпечаток окна в антидетектах.
* Инжектируется маскировка флага автоматизации: `navigator.webdriver = undefined`.

### 9. Безопасное завершение сессии (`Ctrl+C` Resilience)
* Процедура закрытия защищена через `asyncio.shield()`. При нажатии `Ctrl+C` бот сначала корректно отключает CDP, затем передает API команду закрытия, гарантируя, что **BitBrowser успеет синхронизировать cookies и историю на диск**.

## 🚀 Установка и быстрый старт

### 1. Системные требования
* **Python 3.9+**
* Установленный и запущенный **BitBrowser**

### 2. Установка зависимостей
```bash
# Клонирование репозитория
git clone https://github.com/contentino-zavodino/AccountWarmer.git
cd AccountWarmer

# Установка библиотек
pip install -r requirements.txt
playwright install chromium
```

### 3. Подготовка профилей в BitBrowser
1. Запустите приложение **BitBrowser**.
2. Убедитесь, что в настройках включен Local API (по умолчанию порт `54345`).
3. Создайте профили:
   * Для Shorts назовите профиль, например, `YouTube1` (платформа `https://www.youtube.com/`).
   * Для TikTok назовите профиль `TikTok1` (платформа `https://www.tiktok.com/`).
4. **Важно:** привяжите рабочий прокси и авторизуйтесь в аккаунте (руками по логину или импортировав Cookies).

### 4. Запуск софта

#### Интерактивный запуск:
```bash
python3 main.py
```
*(Скрипт выведет меню выбора: `[1] TikTok`, `[2] YouTube Shorts`, `[3] Комбинированный`).*

#### Прямой запуск через аргументы CLI:
```bash
# Только YouTube Shorts
python3 main.py --platform youtube

# Только TikTok
python3 main.py --platform tiktok

# Комбинированный режим (сначала Shorts, затем TikTok)
python3 main.py --platform combined

# Ограничение числа параллельных окон (например, 2 окна одновременно)
python3 main.py --platform youtube --max-concurrent 2
```

*(На macOS можно также запускать скрипт двойным кликом по `./run.sh`).*

## ⚙️ Тонкая настройка (`config.py`)

Все основные параметры вынесены в файл `config.py`:

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `BROWSER_TYPE` | `"bitbrowser"` | Используемый антидетект (`bitbrowser` или `dolphin`) |
| `PROFILE_IDS` | `[]` | Список ID профилей. Если пустой `[]` — софт сам найдет подходящие профили |
| `VIDEOS_PER_SESSION_MIN/MAX`| `35` – `70` | Лимит просматриваемых видео на аккаунт за одну сессию |
| `TIKTOK_LIKE_PROBABILITY` | `0.10` (~10%) | Вероятность лайка в TikTok |
| `TIKTOK_FAVORITE_PROBABILITY`| `0.03` (~3%) | Вероятность добавления в закладки |
| `TIKTOK_READ_COMMENTS_PROBABILITY` | `0.05` (~5%) | Вероятность открытия и чтения комментариев |
| `YOUTUBE_LIKE_PROBABILITY` | `0.10` (~10%) | Вероятность лайка в YouTube Shorts |
| `YOUTUBE_SUBSCRIBE_PROBABILITY` | `0.03` (~3%) | Вероятность редкой органической подписки на автора |
| `COOKIE_WARMUP` | `False` | Если `True`, перед соцсетями посетит нейтральные сайты для нагуливания куки |
| `PROXY_ROTATION_URL` | `""` | Ссылка смены IP для мобильных прокси (GET-запрос перед стартом профиля) |

## 🛑 Остановка работы

* **Штатная остановка:** нажмите комбинацию **`Ctrl + C`** в окне терминала. Софт безопасно завершит сессию, закроет CDP-соединение и сохранит cookies в базу BitBrowser.
* **Автоматическое завершение:** софт остановится сам после достижения лимита просмотренных видео.
