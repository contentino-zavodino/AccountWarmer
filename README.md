# 🚀 Social Account Warmer: TikTok & YouTube Shorts (Dolphin{anty} & BitBrowser + Playwright)

Скрипт для одновременного автоматического прогрева аккаунтов **TikTok** и **YouTube Shorts** с помощью антидетект-браузера **Dolphin{anty}** (или **BitBrowser**) и библиотеки **Playwright**.
Поддерживает работу на **macOS** и **Windows**.

---

## 🌟 Ключевые возможности

1. **Бесплатный браузер Dolphin{anty} по умолчанию**:
   - Работает на официальном **бесплатном тарифе Dolphin{anty}** (до 10 профилей навсегда).
   - Использует бесплатный встроенный **Local API (порт 3001)**.
   - Также сохраняется полная поддержка **BitBrowser** (порт 54345).
2. **Мультиплатформенность**:
   - **TikTok**: просмотр ленты For You, органические лайки по сердечку/дабл-кликом, добавление в закладки, имитация чтения комментариев.
   - **YouTube Shorts**: просмотр ленты `/shorts`, нативные лайки, редкие подписки на авторов (~2-4%), чтение комментариев, автораспознавание и снятие беззвучного режима (unmute).
   - **Комбинированный режим**: последовательный прогрев сначала YouTube Shorts, затем TikTok в рамках одной браузерной сессии.
3. **Максимальная защита от банов и детекта**:
   - **Никаких спам-комментариев**: заменены на естественное открытие и скролл блока комментариев (имитация чтения реальным человеком).
   - **Физические клики и жесты**: наведение по нелинейным кривым Безье с микро-дрожанием, отказ от подозрительных шорткатов (`KeyL`, `KeyC`).
   - **Сохранение отпечатков антидетекта**: исключено принудительное переопределение `viewport`, сохраняются нативные canvas/DPR параметры антидетект-профиля.
4. **Параллельная работа**: одновременный запуск до 3–5 профилей через неблокирующий `asyncio`.
5. **Кроссплатформенный визуальный контроль**: окна браузера автоматически расставляются ровной плиткой/шеренгой на экране как в **macOS**, так и в **Windows**.
6. **Вариативное время просмотра**:
   - Быстрый пропуск (2–5с, ~70% видео).
   - Заинтересованный просмотр (6–11с, ~22% видео).
   - Полный просмотр (12–19с, ~8% видео).

## 🛠️ Быстрый старт с Dolphin{anty}

### Шаг 1. Настройка Dolphin{anty}
1. Запустите приложение **Dolphin{anty}** на вашем Mac.
2. Создайте профиль (например, `TikTok1`).
3. Скопируйте **ID профиля**: в таблице профилей в колонке ID (число, например `12345678`).
4. Вставьте этот ID в файл `config.py`:
   ```python
   PROFILE_IDS = ["12345678"]
   ```
5. *(Совет)*: откройте созданный профиль вручную 1 раз, зайдите на [tiktok.com](https://www.tiktok.com), авторизуйтесь (через QR-код с телефона) и закройте окно. Сессия сохранится!

### Шаг 2. Запуск софта на Mac

В терминале выполните:
```bash
./run.sh
```
Или с флагами:
* **Только TikTok**: `./run.sh --platform tiktok`
* **Только YouTube Shorts**: `./run.sh --platform youtube`
* **Через BitBrowser** (если хотите вернуться на него): `./run.sh --browser bitbrowser`
